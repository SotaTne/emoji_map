# 絵文字Mapについて

emoji_mapは、地図上に絵文字を配置することのできるWebアプリケーションです。ReactとViteを使用して開発されています。

## 開発環境のセットアップ

nodejs pnpm firebase-tools またエミュレーターの起動にjavaが必要ですが、このプロジェクトではmiseを使用しているため、ツールのインストールは非常に簡単に行えます。

miseのinstallができていなければ以下のページからinstallを行ってください

[miseの公式インストールページ](https://mise.jdx.dev/getting-started.html)

miseが有効化を試したい場合は以下のコマンドを実行してください。

```bash
mise doctor
```

miseのツールをインストールしたい場合は以下のコマンドを実行してください

```bash
mise install
```

## firebaseの設定

このプロジェクトでは、Firebaseを使用してデータの保存や認証を行っています。`firebase/firebase-config.example.json`と同じ形式の Firebase configuration object を `firebase/firebase-config.json` に JSON 形式で貼り付けてください。

.gitignoreに含めている理由は、それぞれの個人のFirebaseプロジェクトを使い、想定外のプロジェクトへのアクセスを防ぐためです。
firebase security rulesを適切に設定すれば、firebase-config.jsonが公開されても問題はありませんが、このアプリがデモアプリであることを考慮して、念のため.gitignoreに含めることにしました。

### 隠すべき情報とそうでない情報

アプリ開発を行う際には公開(秘密に)する情報とそうでない情報を正しく認識することが重要です。
秘密にするべき情報はいくつかありますが主な考え方はそれが鍵であるかどうか。そして開発メンバーが複数人いる際に共有させない方が良いかどうかということを判断基準にするといいです。

鍵である情報を秘密にした方がいい理由として、例えばGoogle Map APIは約1万回の表示(画面の再読み込み)を行うだけで数万円かかります。
そして、Chat GPT(OpenAI)やClaude(Antoropic)のAPIは流出すると1日で4~50万円以上使用される可能性もあります。
さらに、データベースへの鍵が漏れると、全てのデータを改ざんされたり、消される可能性もあります。

また、共有させない方がいい情報についてですが、主にエディタの設定と環境に左右される設定です。例えば`node_modules`や`.git`です。`node_modules`はreactやgoogle map apiをつかいやすくするreactのライブラリなどのコードが入っており、これらは非常にサイズが大きく、windows, mac, linuxなどOSによってかなり違いが出る場合があります。
また、独自のエディタ設定をこのプロジェクトで行なっている場合でもそれは含めない方がいいです。
人によって見えやすい色や使っているコンピュータによって何pxが見やすいかなどが変わってきます。

逆に共通にした方がいいものとしてコードのスタイルです。設定で`;`をつけるかつけないか。`'`か`"`のどちらを文字として使うかなどを簡単に設定することができます。これはコードを読みやすくして一貫性を上げるため設定した方がいいです。

## セットアップ

このプロジェクトではfirebase-toolsを使う前提のため、miseのセットアップが終わり次第firebaseへのログインを以下のコマンドを使用して行ってください

ログイン用のurlが表示されるのでそれをクリックすればブラウザが開くのでそこでログインを行ってください。

```bash
firebase login
```

次に、あなたのfirebaseのプロジェクトとこのローカルのフォルダの結び付けを行います。以下のコマンドを実行してどのプロジェクトと結び付けたいかを選択してください。また、ailiasの設定が必要です。firebaseのプロジェクト名は複雑なことが多かったり、設定にそれを直接載せない方が一般的に良いので適切な名前を考えてください。(ex. emoji-app)

```bash
firebase use --add
```

そして、Firestore (データベース) をcliから必要があれば作成してください。ダッシュボード上でFirestoreが存在すればこの手順は飛ばして問題ないです。また、以下のコマンドのasia-northeast1はリージョン(サーバーの場所)です。
asia-northeast1は東京のことを指しているので特別な理由がない限り変更は不要です。

> クラウドは実際にはサーバーが存在します。そのサーバーの都合を気にすることなくアプリにだけ注目して開発できるようにしたものです。
> クラウドという概念は2006年にGoolge の当時の CEO エリック・シュミット によって「データサービスやアーキテクチャは雲のような存在であるサーバー上に存在し、ブラウザやアクセス手段、デバイスによらず雲にアクセスすることができる」という発言で大きく広がりました。
> しかし、国を跨ぐ通信はどうしても遅延が発生しやすくなります。そのため、リージョンを適切に選択することが重要です

```bash
firebase firestore:databases:create --location asia-northeast1
```
